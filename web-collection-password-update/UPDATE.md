# 교사용 비밀번호 변경 기능 업데이트

## 적용하기

이 ZIP 안의 index.html, app.js, editor-auth.js, README.md를 기존 GitHub 저장소의 같은 이름 파일과 교체하세요. 이 안내 파일 UPDATE.md는 선택 사항입니다.

기존 editor-config.js(비밀번호 설정), data.js(프로젝트 목록), styles.css, favicon.svg, preview.cjs와 .github 폴더는 그대로 유지합니다. 이 ZIP에는 기존 데이터나 비밀번호 설정을 덮어쓰는 파일을 넣지 않았습니다. 기존 편집자 로그인 버전에 적용하는 업데이트입니다.

배포가 끝나면 웹페이지를 새로고침하세요. 이전 화면이 남아 있다면 Ctrl+Shift+R로 새로고침합니다.

## 사용하기

1. 기존 비밀번호로 편집자 로그인합니다.
2. 화면 아래 관리 패널에서 ‘비밀번호 변경’을 누릅니다.
3. 현재 비밀번호와 새 비밀번호(12자 이상)를 입력하고 새 비밀번호를 한 번 더 입력합니다.
4. 변경 후에는 편집이 종료됩니다. 새 비밀번호로 다시 로그인합니다.
5. 다른 기기에도 적용하려면 ‘비밀번호 설정 내보내기’로 받은 editor-config.js를 GitHub의 같은 파일과 교체해 배포합니다.

비밀번호 변경은 우선 현재 브라우저에 저장됩니다. 설정 파일을 배포하지 않은 상태에서 브라우저 데이터를 지우면 배포된 설정 파일의 비밀번호로 돌아갑니다. 프로젝트 백업 JSON에는 비밀번호 설정이 포함되지 않습니다. 정적 사이트의 화면 잠금이며 서버 인증을 대신하지 않습니다.
